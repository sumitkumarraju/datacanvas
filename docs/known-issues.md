# Known issues and scope boundaries

- DataCanvas supports one category and one numeric series in v1.
- Inserted charts are flat PNG images; native editable chart parts are outside v1.
- A no-data recipe preserves columns, mapping, transformations, and style but requires source CSV reimport.
- Adobe Express host behavior, permission denial, and theme switching need a real-host run before submission.
- Marketplace listing, privacy notice, terms, support details, and publisher identity require product-owner and legal inputs.
- The production bundle is below Adobe's package limit; Webpack may report a performance advisory for the bundled Spectrum/React runtime.
