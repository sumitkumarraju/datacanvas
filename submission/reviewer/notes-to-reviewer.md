# Notes to reviewer

DataCanvas is a desktop Adobe Express add-on for local UTF-8 CSV chart creation.

1. Choose **Use sample** to load the included synthetic dataset.
2. Confirm the Month/Sales mapping and preview the bar chart.
3. Try line and pie chart types, sorting, duplicate handling, and missing-value handling.
4. Use **Download PNG** to verify the exported image.
5. Use **Add chart to Adobe Express** on an active page to verify PNG insertion.
6. Test both recipe export options. The data-bearing recipe asks for confirmation because it contains original cells; the no-data recipe requires CSV reimport.
7. Import `reviewer/sample.csv` or a CSV containing a blank/non-numeric value to verify row-specific validation and blocked chart creation.

No login, test account, paid feature, cloud service, analytics, telemetry, or AI service is required.
