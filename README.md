## DataCanvas

DataCanvas is the first Adobe Express add-on from the project specification. It imports UTF-8 CSV data locally, validates one category and one numeric series, renders bar/line/pie charts, downloads a PNG, inserts a flat PNG into the current Express page, and exports a versioned recipe.

The add-on does not send CSV data to a backend. The inserted chart is intentionally a flat image; the recipe is the editable source.

## Tools

-   TypeScript

## Setup

1. To install the dependencies, run `npm install`.
2. To build the application, run `npm run build`.
3. To start the application, run `npm run start`.

To test in Adobe Express, enable Add-on Development, run `npm run start`, and connect the displayed local development URL from the Add-on Development panel.

## Current scope

- CSV limits: 2 MB, 5,000 rows, 20 columns.
- Quoted fields, quoted newlines, BOM and Unicode are supported.
- Invalid numeric values block chart creation; missing values can be excluded explicitly.
- Duplicate categories can remain separate, be summed, or be averaged.
- Recipe export warns before including original cells; no-data recipes require CSV reimport.
- `Add chart to Express` uses the documented `app.document.addImage` host API and is guarded against duplicate in-flight operations.

The first implementation slice still needs real-host verification in Adobe Express and the remaining acceptance fixtures from the production specification.
